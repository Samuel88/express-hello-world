# Express Hello World

Progetto Hello World base con Node.js ed Express.

## Installazione

```bash
npm install
```

## Utilizzo

Avvia il server:

```bash
npm start
```

Modalità sviluppo con auto-reload:

```bash
npm run dev
```

Il server sarà disponibile su **http://localhost:3000**

## Configurazione

Porta predefinita: 3000

Per cambiare porta, crea un file `.env`:
```
PORT=8080
```
